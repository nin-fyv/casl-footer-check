# Contributing

Thank you for your interest. **This repository is published read-only.** fyv.ai Ltd. maintains it and does not accept outside pull requests or issues at this time. Pull requests from outside the maintainers are closed automatically. That is no judgement on your change, only on our capacity to review it.

You are free to use, modify and redistribute this code under the Apache License 2.0 (see `LICENSE`), including in a fork. If you publish a fork, please give it a different name (see `TRADEMARKS.md`).

- **Security issues:** please follow `SECURITY.md` and report privately.
- **Our licence promise:** code released here under Apache-2.0 will not be moved to a more restrictive licence.

## For maintainers

- Sign off every commit (`git commit -s`). This adds a `Signed-off-by` line certifying the [Developer Certificate of Origin](https://developercertificate.org/).
- Every new file gets an SPDX header, or a `REUSE.toml` entry. Run `reuse lint` before pushing.
- Examples use invented data only.
